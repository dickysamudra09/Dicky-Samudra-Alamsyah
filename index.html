Tentang

Saya backend developer yang berfokus membangun teknologi untuk pendidikan, dengan latar belakang di dua dunia: teknologi dan pendidikan bahasa. Saya berpengalaman mengembangkan sistem berbasis web, termasuk Si Jerman, platform belajar bahasa Jerman berbasis AI di mana saya berperan sebagai ketua tim sekaligus developer, serta sistem booking (Laravel) dan aplikasi inventaris (Flutter) saat magang sebagai IT Support di Malang Creative Center, termasuk memimpin proyek booking sebagai Project Manager.

Saat ini saya memperdalam DevOps lewat Docker dan Google Cloud Skills Boost, dengan langkah berikutnya men-deploy proyek saya sendiri ke cloud, karena saya ingin menjadi developer yang memahami proses secara utuh, dari menulis kode sampai deployment.
